This is a [Vue 3](https://vuejs.org/) project scaffolded with [Vite](https://vite.dev/).

## Getting Started

Install dependencies, then run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) with your browser to see the result.

You can start editing the page by modifying `src/App.vue` or the components in `src/components/`. The page auto-updates as you edit the files.

Styling is handled with [Tailwind CSS v4](https://tailwindcss.com/) via the `@tailwindcss/vite` plugin — theme tokens live in `src/style.css`.

## Build

```bash
npm run build
```

Type-checks the project with `vue-tsc` and outputs a production build to `dist/`.

## Deploy on Vercel

This is a static Vite build, so it deploys to [Vercel](https://vercel.com/) with zero configuration — Vercel auto-detects the Vite framework preset.
