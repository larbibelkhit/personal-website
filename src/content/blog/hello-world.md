## Why a blog

I wanted a place to write about the things I build, the problems I run into, and what I learn along the way. This is that place.

Posts here are plain Markdown files, rendered with a table of contents on the side so longer write-ups are easy to navigate.

## What to expect

Expect a mix of:

- Notes on projects I'm working on
- Short write-ups on things I learn
- Occasional code snippets, like the one below

function greet(name: string): string {
